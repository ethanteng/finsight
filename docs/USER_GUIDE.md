## Introduction

Ask Linc is an AI-powered financial analysis platform designed to help you understand, optimize, and manage your complete financial picture. By combining advanced artificial intelligence with real-time market data and seamless integration with your financial institutions, Ask Linc provides personalized financial insights that adapt to your unique situation.

### What Makes Ask Linc Different

**Traceable Financial Analysis**: Financial answers are grounded in canonical snapshots and deterministic calculations, so displayed values can be traced to their source data and as-of time.

**Intelligent Context Building**: Unlike traditional financial apps that treat each question in isolation, Ask Linc builds context across conversations. The AI remembers your previous questions and proactively connects new information to provide comprehensive analysis.

**Real-Time Market Intelligence**: Access current rates, economic indicators, and market data from 60+ exchanges worldwide, integrated directly into your financial advice.

**Holistic Coverage**: Get advice about any financial institution or product—not just those you've connected. The platform uses real-time search to provide current information about rates, products, and services from banks, credit unions, fintech companies, and investment platforms.

**Unified Financial Picture**: Seamlessly combine banking accounts (via Plaid), investment accounts (via SnapTrade), home values, and manual accounts into a single comprehensive view of your financial health.

## Retirement Planning

### Retirement Portfolio Analysis

Ask Linc provides sophisticated retirement portfolio analysis based on historical market data:

**What It Analyzes:**
- Your current investment portfolio composition
- Historical performance patterns
- Withdrawal sustainability
- Sequence risk assessment
- Inflation protection

**Required Information:**
- Current age
- Retirement age (or current retirement status)
- Annual withdrawal amount (in today's dollars)
- Life expectancy (defaults to 95)

**Analysis Results:**

**Portfolio Characteristics:**
- Growth Potential: High/Moderate/Low
- Drawdown Resistance: High/Moderate/Low
- Withdrawal Fragility: High/Moderate/Low
- Inflation Protection: High/Moderate/Low

**Tradeoffs:**
- **Upside**: What this allocation historically provided
- **Downside**: What this allocation historically lacked or risked

**Key Metrics:**
- Equity allocation percentage
- Withdrawal rate (annual withdrawal as % of portfolio)
- Years of expenses covered
- Historical sustainable withdrawal rates (percentiles)

**Stress Test Results:**
- Survival rate (% of historical sequences where portfolio sustained withdrawals)
- Depletion percentiles (years until depletion at different percentiles)
- Worst-case scenarios

**Data Quality:**
- Confidence level (High/Medium/Low)
- Completeness (% of holdings with full data)
- Assumptions and proxies used

**How to Use:**
Simply ask retirement-related questions:
- "How is my portfolio positioned for retirement?"
- "Will my current investments support a $100,000 annual withdrawal starting at age 68?"
- "What's my retirement readiness?"
- "Analyze my portfolio for retirement planning"

**Important Disclaimers:**
- Past performance does not predict future results
- Analysis assumes fixed real-dollar withdrawals
- Portfolio mapped to broad market indices
- Does not account for taxes, fees, or transaction costs
- For informational purposes only—not financial advice

## Privacy & Security

### Data Handling

Ask Linc stores connected financial data and profile information so it can build authenticated, question-specific analysis context. Profile data is encrypted at rest. AI requests receive the context needed to answer the question; review the current privacy policy before connecting accounts or submitting sensitive information.
- Seamless user experience
- Industry-leading security

### Security Features

**Authentication:**
- Secure JWT-based authentication
- Email verification required
- Password reset with secure tokens
- Session management

**Data Protection:**
- **Encryption at Rest**: All sensitive data encrypted using AES-256-GCM
- **Encryption in Transit**: All data transmitted over HTTPS
- **Profile Encryption**: User profiles encrypted with unique initialization vectors
- **Secure Storage**: Database-level encryption

**Account Security:**
- Read-only access (Ask Linc cannot move money)
- OAuth-based authentication (no password storage)
- Bank-level security standards
- Regular security audits

**User Data Isolation:**
- Complete data separation between users
- User-specific data filtering
- No cross-user data access
- Secure API endpoints

**Your Data, Your Control:**

- Delete all data with one click
- Export your data
- Edit or delete your profile

**Privacy Settings:**
- Control what data is analyzed
- Manage profile information

**Compliance:**
